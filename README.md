# Лендинг репетитора по математике и физике

Простой одностраничный сайт для репетитора.

## Услуги

- **Индивидуальные занятия**: 1000 ₽/час (математика, физика)
- **Групповые занятия**: 500 ₽/час на человека (3-4 человека)

## Деплой

Сайт размещен на GitHub Pages.

## Настройка контактов

Отредактируйте `index.html` и замените:
- `+7XXXXXXXXXX` — ваш номер телефона
- `yourusername` — ваш Telegram username
